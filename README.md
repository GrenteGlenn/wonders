# ✨ Wonders

**Wonders** est un projet frontend créatif mettant en avant des **interactions visuelles**, des **animations** et une **expérience utilisateur immersive**.

Ce projet a été conçu comme une exploration visuelle et technique, avec pour objectif de démontrer des compétences en **développement frontend**, **mise en page**, et **animation**.

---

## 🚀 Fonctionnalités

- Interface visuelle immersive
- Animations et transitions fluides
- Expérience utilisateur orientée design
- Responsive (desktop et mobile)
- Structure frontend claire et maintenable

---

## 🧩 Stack technique

- JavaScript
- HTML
- CSS
- (Framework ou librairie si applicable)

## 📦 Prérequis

- Navigateur web moderne
- Node.js ≥ 18 (si build ou bundler utilisé)
- npm install
