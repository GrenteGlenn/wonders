🛡️ Politique de Confidentialité

Dernière mise à jour : 12/07/2025

Bienvenue sur notre page de politique de confidentialité. Nous nous engageons à protéger vos données personnelles et à respecter votre vie privée.

Qui sommes-nous ?

Ce site web a été développé dans le cadre d’un projet de fin d’études par des étudiants en Master. Notre objectif est de proposer une plateforme qui centralise tous les besoins liés à l’organisation d’un voyage (recherche de destinations, vols, hôtels, etc.).

Données collectées

Nous ne collectons aucune donnée personnelle sensible à votre insu. Cependant, certaines données techniques peuvent être automatiquement collectées :

  • Adresse IP
  • Type de navigateur et système d’exploitation
  • Données de navigation (pages consultées, temps passé, clics, etc.)

En cas d’utilisation de fonctionnalités spécifiques (recherche, géolocalisation, chatbot IA, etc.), certaines informations peuvent également être utilisées temporairement.

Technologies et services tiers utilisés

Nous utilisons les services suivants :

  • Google Maps API : géolocalisation, affichage des cartes, recherche de lieux
  • Google Images API : illustration visuelle des destinations
  • OpenAI API (ChatGPT) : assistance intelligente à la planification de voyage

Ces services peuvent collecter certaines données techniques. Nous vous invitons à consulter leurs propres politiques :
Politique de confidentialité de Google | Politique de confidentialité d’OpenAI

Utilisation des données

Les données éventuellement collectées sont utilisées pour :

  • Assurer le bon fonctionnement de la plateforme
  • Améliorer l’expérience utilisateur
  • Fournir des résultats personnalisés
  • Gérer les performances du site via des outils d’analyse anonymes

Cookies

Notre site peut utiliser des cookies pour :

  • Mesurer l’audience (Google Analytics ou équivalent)
  • Faciliter la navigation (préférences utilisateur)

Vous pouvez désactiver les cookies dans les paramètres de votre navigateur.

Stockage et sécurité

Nous ne stockons aucune donnée personnelle nominative sur nos serveurs. Les données techniques sont traitées de manière anonyme ou pseudonymisée. Nous nous efforçons d'assurer la sécurité de nos services.

Vos droits (RGPD)

Si vous êtes utilisateur basé dans l’Union Européenne, vous avez les droits suivants :

  • Accès à vos données
  • Rectification ou suppression
  • Limitation ou opposition au traitement
